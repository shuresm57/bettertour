# BetterTour Client

Svelte 5 SPA for artists and venues. Handles dashboards, show management, real-time booking requests, and authentication.

Built with Vite, Svelte 5, Tailwind CSS, and Skeleton UI.

## Structure

- `src/pages/` — artist, venue, and public pages
- `src/components/` — shared UI components grouped by concern
- `src/services/` — client-side business logic
- `src/stores/` — shared Svelte stores
